# Portfolio (Node Server)
A version of my portfolio website packaged in a node server

# Deployment
1. Install dependencies
    - express:\
    ```npm i express```
2. Start server\
```npm run start```
    - Server will run on http://localhost:3000

# Routes
- / - index.html (main page)
- / - .html ()
- /.*/ - error.html (404 page)
